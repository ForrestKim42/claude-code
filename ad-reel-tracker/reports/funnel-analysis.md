## 1. 풀퍼널 구조

```
[Instagram 릴스 노출]
        ↓  CTR (클릭률)
[랜딩페이지 세션 진입]
        ↓  채팅 참여율
[채팅 시작]
        ↓  CTA 도달율 (chat_count = 3)
[전화번호 입력 CTA 노출]
        ↓  CTA 전환율
[전화번호 제출 = 최종 전환]
```

## 6. 핵심 인사이트 및 가설

### 가설 1 — CTR과 전환율은 반비례한다 `[확도 ★★★★☆]`

지여닝(6.90%)과 서윤(5.74%)의 CTR이 높지만, 뷰→전화 최종 전환에서 신소윤(0.104%)이 1위. **클릭률이 높다고 전환이 높은 게 아님.** 광범위한 노출이 낮은 품질의 트래픽을 유발할 수 있음.

> 릴스 콘텐츠가 **'호기심 클릭'** 을 유도하는지, **'진지한 관심 클릭'** 을 유도하는지가 갈림.

### 가설 2 — 재생배율(Replay Rate)이 높을수록 전환 품질이 높다 `[확도 ★★★☆☆]`

| 계정 | 재생배율 | 뷰→전화 |
|------|--------:|-------:|
| 지여닝 | 4.7x | 0% |
| 신소윤 | 3.5x | 0.104% |
| 에스더 | 3.2x | 0.050% |
| 하나 | 3.1x | 0.015% |
| 서윤 | 2.2x | 0.079% |

재생배율이 높다고 전환이 바로 높아지지는 않으나, 지여닝의 0% 전환은 별도 기술 이슈(하단 참조)로 보임. 일반적으로 반복 시청(높은 재생배율)은 관심도 신호.

### 가설 3 — 하나(@ha_n_a0.6)의 CTR(0.49%)이 비정상적으로 낮다 `[확도 ★★★★★]`

6,597 Views에서 32세션밖에 발생하지 않음. 다른 계정 평균 CTR이 3~7%인 것에 비해 **10배 낮음**. 릴스 → 랜딩 링크가 정상 연결됐는지 확인 필요. 링크 문제가 없다면, 하나의 팔로워 특성상 릴스를 소비만 하고 외부 링크를 클릭하지 않는 층임을 의미.

> 하나 계정의 채팅율(40.6%)과 CTA전환율(12.5%)은 우수 → 링크 클릭만 해결되면 최상위 퍼포머 가능성.

### 가설 4 — 지여닝(@caiime_pretty) CTA도달율 87.5%에도 전화제출 0건은 기술 버그 `[확도 ★★★★★]`

CTA(chat_count=3)에 7명이 도달했음에도 0건 제출. 서윤 기준 동일 구간 전환율 9.2% → 통계적으로 최소 1건 이상 발생해야 정상. **특정 디바이스·브라우저 환경에서 전화번호 입력 UI 렌더링 오류 가능성.**

### 가설 5 — chat_count=3이 CTA 트리거이며, 2→3 이탈이 핵심 병목 `[확도 ★★★★★]`

전화 제출 29/33건(88%)이 chat_count=3에서 발생. chat_count=2 세션 136건에서 전화 제출 0건. AI 3번째 응답 시점에 전화번호 CTA가 노출되는 구조. **2번 대화하고 이탈한 136명이 3번만 넘겼다면 이론상 12건 추가 전화제출 가능.**

## 8. 현재 수치 기준 시뮬레이션

> 만약 하나(@ha_n_a0.6)의 CTR이 서윤 수준(5.74%)으로 개선된다면:

```
현재: 6,597 Views × 0.49% CTR × 40.6% 채팅 × 12.5% 전환 = 1.6건
개선: 6,597 Views × 5.74% CTR × 40.6% 채팅 × 12.5% 전환 = 19.2건
                                                    → +17.6건 추가 전화제출
```

> 만약 chat_count 2→3 이탈만 절반으로 줄인다면:

```
현재 이탈 136건 × 50% 유지 × 8.6% 전환 = +5.8건 추가
```
